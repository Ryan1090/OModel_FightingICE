# Generated characters

This is the output folder for fresh runs. The default destination is
`catalogue_001`, created when Run starts.

Generated catalogues, archives, logs and run indexes in this folder are ignored
by Git. This README and its `.gitignore` are retained as package essentials.

Previous catalogues and archives are preserved in untracked research storage,
outside `approved work`. They are not generator dependencies. No completed
catalogue is bundled here.
